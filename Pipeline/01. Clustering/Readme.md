# Canada Clustering Pipeline developed by BCG X Delivery

Steps to execute the code:

1. Open the folder by VS code
2. Create a virtual Environment (Only to be done if using the pipeline for the first time)
3. Activate the virtual Environment --> .\.venv\Scripts\Activate
4. Install the requirements.txt file --> pip install -r requirements.txt (Only to be done if creating the Virtual Environment for the first time)
5. To run individual code paste "python Data_Preparation.py" or "python Clustering.py" in the terminal
